# Design analysis

Audience: beginner discussing an undergraduate research proposal.
Learning objective: distinguish AIS source data, synthetic trajectory augmentation, domain adaptation, and evaluation using real radar.
Layout: bento-grid with numbered process cards; landscape 16:9.
Style: craft-handmade, clean cream background, navy typography, teal AIS, amber synthetic observations, blue radar.
Language: English. Backend: built-in image_gen.
Scope: proposed experimental framework, not established results. No claim of criminal-intent recognition or performance on vessels that never transmit AIS.
