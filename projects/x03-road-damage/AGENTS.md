# X03 road-damage project workspace

- Use this directory as the storage root for all new X03 project files: notes, scripts, notebooks, configurations, data manifests, results and artifacts. Organise subdirectories as needed.
- Record every substantive project action in `log.md`: research/source checks, decisions, file creation or edits, commands/experiments, findings, failures, verification and next steps.
- Append dated entries in Asia/Colombo time. Record actual outcomes and distinguish plans, estimates and hypotheses from completed work and measured results.
- Update the log before ending each work session. Group routine tool calls into a clear activity entry; retain experiment commands/settings and output paths when reproducibility requires them.
- Keep all logged paths relative to this project directory where possible. Do not put credentials, tokens or other secrets in the log.
- Historical X03 material elsewhere in the repository remains reference material unless the user requests migration. Preserve its links when editing shared discovery documents.
